# LeadLoop — Frontend

Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 client for the AI Event Lead Manager.

See the [root README](../README.md) for full setup instructions, the API contract, and key decisions.

```bash
npm install
npm run dev   # http://localhost:3000 (expects the FastAPI backend on :8000)
```

Set `NEXT_PUBLIC_API_URL` (see `.env.local.example`) to point at a deployed backend.
